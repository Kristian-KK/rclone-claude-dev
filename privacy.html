Privacy policy – rclone claude-dev

Last updated: 5 November 2026

Who uses this app

Only the owner of the Google account that created it. It is not available to the public.

What data it accesses

Files in the owner's own Google Drive, through the Google Drive API permission granted at sign-in. The data is used only to sync those files between Google Drive and the owner's own private server.

Storage

Sign-in tokens are stored only on the owner's private server. File contents move only between the owner's Google Drive and that server.

Sharing

No data is sold, shared with or transferred to any third party, and none is used for advertising or to train AI models.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops all access immediately.
